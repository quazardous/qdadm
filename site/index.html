The Vue 3 admin framework an AI agent can drive.

Declare an entity once: its list, form, routes and permission checks follow. Then attach an agent to the running app — it reads the page, clicks and fills forms like a user, takes screenshots, and is told what every action caused.

Why qdadm

CRUD from one declaration

ctx.entity('books', new EntityManager({
  name: 'books',
  labelField: 'title',
  fields: { title: { type: 'text', required: true } },
  storage: new MockApiStorage({ entityName: 'books' })
}))
ctx.crud('books', {
  list: () => import('./pages/BookList.vue'),
  form: () => import('./pages/BookForm.vue')
})

Swap the storage for your API; the pages, routes and permissions stay.

An agent drives the live app

npx qdadm-mcp-relay --stdio

An MCP server over the app running in your browser: a snapshot of the page with a ref per element, click and fill like a user, screenshots, console and network — and after each action, the errors, toasts and missing translations it caused. qdadm-mcp

Extend without forking

TypeScript everywhere. Hooks, signals and zones change behaviour from the outside; modules bring their own entities, routes and menu. PrimeVue themes apply through CSS variables.
